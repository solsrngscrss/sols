  **Solution:** Check for a **Sols Rng Script Roblox** patch in the changelog above. Most boss-related fixes ship within 24 hours of a game update.

  **Solution:** Set `autoFishEnabled = false` in `config.lua`, restart, then re-enable. This forces a fresh calibration cycle.

  The **Aura Giver Sols Rng Script** requires both players to be on the same server. Cross-server transfers are not supported.
  **Solution:** Confirm both players are in the same lobby, then retry the transfer from the GUI panel.

- ❌ **Script crashes on mobile devices**
  Mobile executors have stricter memory limits. Running all modules of the **Sols Rng Script** simultaneously may exceed those limits.
  **Solution:** Enable `lowMemoryMode` in the configuration and activate only essential modules like **Auto Craft Sols Rng Script** or a single automation loop at a time.
